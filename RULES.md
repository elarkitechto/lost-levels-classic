# Publication rules

Publish source, documentation and licenses only. Exclude ROMs, BIOS files,
extracted game assets, saves, personal configuration, credentials, logs and
private notes. Use relative paths and neutral examples. Review staged files,
Git metadata, archives and binaries before publishing. Preserve third-party
credits and license obligations. New history uses elarkitechto with the GitHub
noreply address; never inherit a workstation identity.

The user-authorized gameplay comparison at docs/before-after.png is public documentation. It must contain game pixels and neutral labels only, with no personal metadata.
